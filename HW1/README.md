# Homework 1: Financial Computing

## Overview

This folder contains my solutions for Homework 1 of the Financial Computing course at the University of Illinois Urbana-Champaign.

The assignment focuses on applying C++ programming and Python-based analysis to financial computing.

## Contents

- `IE523Fa26-Homework1.pdf`: Homework problem set.
- `basic_stock.cpp`: C++ implementation of the stock class.
- `basic_stock.hpp`: Header file for the stock class.
- `portfolio.cpp`: C++ implementation of the portfolio class.
- `portfolio.hpp`: Header file for the portfolio class.
- `main.cpp`: Main C++ program.
- `portfolio.txt`: Portfolio input file.
- `python_report/`: Python code used for data analysis, visualization, and report generation.
- `report.csv`: Report results.
- `simulation_results.csv`: Simulation results.
- `README.md`: Documentation for this assignment.

- C++
- Python
